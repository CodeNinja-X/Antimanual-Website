# Redesign ONLY the Website Hero Banner

Redesign ONLY the existing hero/banner section.

Do not modify the rest of the website.

The website is an **information and product-promotion website** for Antimanual.

It is NOT the actual automation application.

---

## HERO STRUCTURE

The hero should have exactly these core elements:

1. **Small TAG / CATEGORY**
2. **Strong TITLE**
3. **Short PARAGRAPH**
4. **Product / Character VISUAL**
5. **DOWNLOAD SOFTWARE button**

The visual hierarchy must be extremely clear.

---

# 1. TAG

Create a small, distinctive product tag above the title.

Example:
**SUBLIMATION AUTOMATION**
or:
**APPAREL PRODUCTION AUTOMATION**
or:
**DESIGN WORKFLOW AUTOMATION**

The tag should feel like part of the brand, not a generic badge.
Keep it short.

---

# 2. TITLE

Create a strong, memorable headline.

Example direction:
**STOP DOING THE REPETITIVE WORK.**

Alternative direction:
**AUTOMATE THE WORKFLOW.**

The title should be:
- Large
- Bold
- Highly readable
- Visually dominant
- Product-specific

Do not use generic marketing language such as: "The future of productivity is here."
The headline should communicate the actual product benefit.

---

# 3. PARAGRAPH

Add a concise supporting paragraph.

Example:
> Antimanual automates repetitive apparel-production tasks like renaming, resizing, grading, nesting, and preparing designs for print.

Keep it short. Do not create a large wall of text.
The visitor should understand the product in a few seconds.

---

# 4. DOWNLOAD BUTTON

The primary CTA should be:
**DOWNLOAD ANTIMANUAL**

This is the main action of the hero.
The button should feel important and visually distinctive.

Optional secondary text near the button:
**Windows • Desktop Software**

Only show this if it is accurate.

Do NOT use:
- Register
- Sign Up
- Start Free Trial
- Create Account
- Login

The website does not require registration.

---

# 5. CHARACTER / PRODUCT VISUAL

The hero should contain a strong visual character/product illustration.
The character should visually represent Antimanual.

Possible direction:
A distinctive mascot/character interacting with:
- Design files
- Apparel
- Photoshop-style artwork
- Production sheets
- Automation workflow
- Computer interface
- File thumbnails

The character should NOT look like a random stock illustration.
It should feel like an identifiable part of the Antimanual brand.

---

# 6. VISUAL COMPOSITION

Do NOT use a generic layout. Create an art-directed composition.

---

# 7. CHARACTER INTEGRATION

The character should feel integrated into the design.
Use composition, depth, and layering to make the character part of the story.

---

# 8. PRODUCT VISUALS

Around the character, use subtle product-related elements:
- PSD file labels
- Size labels
- Design thumbnails
- Apparel silhouettes
- Production sheets
- File names
- Workflow lines
- Dimension markers

---

# 9. VISUAL STYLE

The hero should feel:
- Premium
- Modern
- Distinctive
- Technical
- Creative
- Apparel-production focused

Avoid generic SaaS visuals, random blobs, or excessive glassmorphism.

---

# 10. INFORMATION HIERARCHY

The eye should naturally follow:
TAG -> TITLE -> PARAGRAPH -> DOWNLOAD
while the character/product visual creates the visual focal point.

---

# 11. RESPONSIVE DESIGN

Desktop: Split layout with Left (Tag, Title, Paragraph, Download) and Right (Character + product visual).
Mobile: Stacked layout with Tag, Title, Paragraph, Download, then Character + product visual.

---

# 12. ANIMATION

Use subtle entrance animations and polished hover states.

---

# 13. BUTTON BEHAVIOR

Connect **DOWNLOAD ANTIMANUAL** to the existing software download/release destination in the project if one exists.

---

# 14. DO NOT CHANGE OTHER SECTIONS

Only modify the Hero / Banner section.
Do not redesign Features, About, Screenshots, Pricing, Footer, Navigation, or existing app functionality.
